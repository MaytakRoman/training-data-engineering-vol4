# Том 4 — код и результаты после рецензии

Версия комплекта: 1.1.0, 14 октября 2026 года.
Код извлечён из исправленного Word-документа; контрольные суммы указаны в SHA256.json.
Внешние библиотеки и подключение к сети не требуются. Проверка выполнена на Linux в Python 3.12.14.
Запуски на Windows и macOS не выполнялись; соединения SQLite теперь гарантированно закрываются.

## Запуск

```sh
python3 release_store.py
python3 special_checks.py
python3 corpus_lab.py --out lab_results
python3 control_experiments.py --out control_results
```

Краткие листинги `listing_*.py` можно запускать отдельно. Все шесть кратких листингов,
три автономных приложения и дополнительные контрольные опыты исполнены после извлечения из DOCX.
Результаты контроля совпали с результатами рабочих исходников.

## Состав

- `release_store.py`: локальный каталог, манифест и условная публикация.
- `special_checks.py`: доступность измерений, окна, предпочтения и события.
- `corpus_lab.py`: исходный синтетический опыт, генератор сохранён; исправлен верхний индекс квантиля.
- `control_experiments.py`: случайная навигация, тест с навигацией, равный бюджет слов,
  логистический фильтр и фактические парные переходы.
- `lab_results/report.json`: исходные пять повторений.
- `control_results/report.json`: 160 комбинаций основного контроля, проверки фильтра
  и сохранённые предсказания seed 17.
- `execution_report.json`: вывод и коды завершения автономных и кратких листингов.

## Границы интерпретации

Документы полностью синтетические. Независимая проверка фильтра также синтетическая,
её целевые метки определены основной областью порождённого тела, а не флагом damaged.
Реальный корпус с экспертной разметкой критических фактов не использовался.
Равный бюджет измеряется кириллическими словами регулярного выражения; это не бюджет токенов LLM.
Тест с навигацией намеренно не применяет извлечение на входе и является диагностикой переноса.

## Ключевые исправления

- Остаток получения: 150 временных отказов + 400 по условиям = 550.
- Очередь карантина: 900 + 50 − 620 = 330.
- Групповой пример: 620 + 19 × 20 = 1000; строковая оценка 0,8550.
- Бюджеты сигнатур LSH явно обозначены как 100, 128 и 128.
- Фактические переходы seed 17: оба верны 16, оба неверны 118,
  исправления 424, регрессии 42; разность 0,6367.
- Бутстреп: индексы 125 и 4874 для 5000 повторов; интервал [0,5883; 0,6850].
- Источники о каппа, интервале Уилсона, бутстрепе, формуле Литтла,
  накоплении синтетики, FineWeb2 и MERA добавлены в книгу.
- Переход Presidio к data-privacy-stack подтверждён на странице проекта.

ISBN, УДК, ББК и персональные сведения о рецензентах не присваивались автоматически;
на обороте титула указан порядок их издательского оформления.
